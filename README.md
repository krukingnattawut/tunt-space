# TUNT Space v01

ระบบเฝ้าระวังและดูแลสุขภาพจิตนักเรียนกลุ่มเสี่ยงแฝงเชิงรุก
(นักเรียน: เช็กอินอารมณ์ + กระดานระบายไม่ระบุตัวตน / ครู: แดชบอร์ดหลังบ้าน)

## v01 ทำอะไรได้บ้าง

- นักเรียนสมัครด้วยชื่อจริง + เบอร์ติดต่อ (เก็บไว้ให้ครูเห็นเท่านั้น) → ได้บัญชีไม่ระบุตัวตน เช่น `TUNT-8606`
- เช็กอินอารมณ์รายวัน (5 ระดับ)
- โพสต์กระดานระบายแบบไม่ระบุตัวตน กดไลก์ได้ — ระบบสแกนคำเสี่ยงอัตโนมัติ (v01 ใช้ keyword matching ง่ายๆ)
- ครูแนะแนวล็อกอินด้วยรหัสผ่านกลาง เข้าดูแดชบอร์ด เห็นชื่อจริง/เบอร์โทร คู่กับอารมณ์ล่าสุดและระดับความเสี่ยง
- **ยังไม่ทำ (ไว้ v02):** แบบทดสอบจิตวิทยา (MBTI, SDQ ฉบับเต็ม ฯลฯ), แชทบอท, ระบบบัญชีครูแบบหลายคน

## โครงสร้างโปรเจกต์

```

  app/

    feed/page.js               → กระดานระบาย
    teacher/page.js              → แดชบอร์ดครู (มีล็อกอินในตัว)
    api/
      register/               → สมัครนักเรียนใหม่
      checkin/                 → บันทึกอารมณ์
      posts/                     → โพสต์/อ่านกระดานระบาย
      posts/like/                 → กดไลก์
      teacher/login/                → ล็อกอินครู (คุกกี้ 8 ชม.)

```

## วิธี Deploy บน Vercel (ทำตามลำดับ)

### 1. เตรียมโค้ดขึ้น GitHub
1. สร้าง repository ใหม่บน GitHub (เช่น `tunt-space`)
2. ในเครื่องของคุณ ที่โฟลเดอร์นี้ รันคำสั่ง:
   ```bash
   git init
   git add .
   git commit -m "TUNT Space v01"
   git branch -M main
   git remote add origin https://github.com/<username>/tunt-space.git
   git push -u origin main
   ```

### 2. Import โปรเจกต์เข้า Vercel
1. เข้า https://vercel.com → ล็อกอิน (สมัครฟรีด้วย GitHub ได้เลย)
2. กด **Add New → Project**
3. เลือก repository `tunt-space` ที่เพิ่ง push ไป → กด **Import**
4. หน้าตั้งค่า ปล่อย default ทั้งหมด (Vercel จับ Next.js ให้อัตโนมัติ) → กด **Deploy**
5. รอสักครู่ ระบบจะ build และให้ลิงก์ เช่น `https://tunt-space.vercel.app` (ตอนนี้เว็บจะยัง error เพราะยังไม่มีฐานข้อมูล ข้ามไปข้อ 3 ต่อ)

### 3. เชื่อมฐานข้อมูล (Neon Postgres ฟรี ผ่าน Vercel โดยตรง)
1. ในหน้าโปรเจกต์บน Vercel → แท็บ **Storage**
2. กด **Create Database** → เลือก **Postgres** (ขับเคลื่อนโดย Neon) → เลือก region ใกล้ไทยที่สุด (เช่น Singapore) → **Create**
3. เมื่อสร้างเสร็จ กด **Connect** เพื่อเชื่อมฐานข้อมูลเข้ากับโปรเจกต์ `tunt-space` — Vercel จะใส่ตัวแปร `DATABASE_URL` ให้อัตโนมัติ
4. ไปที่แท็บ **Deployments** → กดจุดสามจุดของ deployment ล่าสุด → **Redeploy** (เพื่อให้ตัวแปรใหม่มีผล)

### 4. ตั้งรหัสผ่านครู
1. ไปที่ **Settings → Environment Variables**
2. เพิ่มตัวแปร `TEACHER_PASSWORD` ค่าที่ตั้งเอง (อย่าใช้ค่า default `tunt2026`)
3. Redeploy อีกครั้งให้ตัวแปรมีผล

### 5. สร้างตารางฐานข้อมูล (ทำครั้งเดียว)
เปิดเบราว์เซอร์ไปที่:
```
https://<โดเมนของคุณ>.vercel.app/api/init-db
```
ถ้าเห็น `{"ok":true,"message":"Database ready"}` แปลว่าเรียบร้อย พร้อมใช้งานจริง

### 6. ทดสอบ
- หน้านักเรียน: `https://<โดเมนของคุณ>.vercel.app/`
- หน้าครู: `https://<โดเมนของคุณ>.vercel.app/teacher` (ใช้รหัสผ่านที่ตั้งในข้อ 4)

## สอนใช้งานสำหรับครูแนะแนว

1. เปิดลิงก์ `/teacher` แล้วใส่รหัสผ่านที่ผู้ดูแลระบบตั้งไว้
2. หน้าแดชบอร์ดจะแสดง:
   - **การ์ดสรุปด้านบน** (ถ้ามีโพสต์ที่ระบบตรวจพบคำเสี่ยง จะขึ้นเตือนก่อนตารางเสมอ)
   - **ตารางนักเรียนทั้งหมด** เรียงตามคนที่สมัครล่าสุด แสดงชื่อจริง เบอร์ติดต่อ อารมณ์ล่าสุด จำนวนครั้งที่เช็กอินใน 7 วัน และระดับความเสี่ยง
3. ระดับความเสี่ยง (v01 เป็นกฎง่ายๆ ยังไม่ใช่การประเมินทางคลินิก):
   - แดง **เสี่ยงสูง** — มีโพสต์ที่ตรวจพบคำเสี่ยง
   - เหลือง **เฝ้าระวัง** — อารมณ์ล่าสุดคือ "เหนื่อยใจ/แย่มาก" หรือไม่ได้เช็กอินเลยใน 7 วัน
   - เขียว **ปกติ** — เช็กอินสม่ำเสมอ อารมณ์อยู่ในเกณฑ์ปกติ
4. ข้อมูลอัปเดตทุกครั้งที่รีเฟรชหน้าเว็บ (v01 ยังไม่มีระบบแจ้งเตือนแบบ real-time)

**ข้อควรระวัง:** รหัสผ่านครูใน v01 เป็นรหัสกลางใช้ร่วมกันทุกคน (ยังไม่มีระบบบัญชีแยกรายบุคคล) — เหมาะสำหรับช่วงนำร่องเท่านั้น ก่อนขยายผลควรอัปเกรดเป็นระบบล็อกอินแยกรายคน

## อัปเดต v02 — มีอะไรใหม่

### ระบบสมาชิกเต็มรูปแบบ
- สมัครสมาชิกจริง (ชื่อ-นามสกุล, ชั้นเรียน, เบอร์โทร, ไอดี, รหัสผ่าน) แทนการกรอกแค่ชื่อ-เบอร์แบบ v01
- ล็อกอิน / ล็อกเอาต์ ด้วย session cookie ที่เก็บในฐานข้อมูล (ตาราง `sessions`)
- รหัสผ่านถูกเข้ารหัสด้วย bcrypt ก่อนบันทึกเสมอ

### โปรไฟล์ผู้ใช้
- ตั้งชื่อเล่น เลือกอวาตาร์ (emoji) และสีประจำตัวได้ที่หน้า `/profile`
- มีกล่องข้อความคุยกับครูแนะแนวโดยตรงในหน้าเดียวกัน

### Responsive ทั้ง PC และมือถือ
- จอกว้าง (md ขึ้นไป) แสดงเป็น sidebar ซ้ายมือ
- จอมือถือแสดงเป็น bottom navigation แบบเดิม
- ทุกหน้า (ยกเว้นหน้าแรก) มีปุ่มย้อนกลับ (←) ที่มุมซ้ายบน

### ฟีเจอร์ใหม่ (เชลล์ UI ใช้งานได้ ยังไม่ลงลึกระบบหลังบ้าน)
- **`/tests`** — รายการแบบทดสอบ 6 แบบ กดดูได้ แต่ตัวแบบทดสอบจริงยังไม่เปิดให้ทำ (ขึ้นข้อความ "กำลังพัฒนา")
- **`/chat`** — แชทบอทแบบ rule-based เหมือนต้นแบบ พร้อมปุ่ม "อยากคุยกับครูแนะแนวจริงๆ" ที่ส่งข้อความเข้าระบบ Messages จริง
- **`/news`** — หน้าอ่านข่าวสาร/กิจกรรม ดึงจากฐานข้อมูลจริงที่ครูเป็นคนเพิ่ม

### หน้าครูแนะแนวยกระดับเป็น Admin Panel
เข้าที่ `/teacher` เหมือนเดิม แต่ตอนนี้มี 4 แท็บ:
1. **แดชบอร์ด** — เหมือน v01 (รายชื่อ + ระดับความเสี่ยง)
2. **ข้อความ** — กล่องข้อความจากนักเรียนทุกคน แยกเป็นรายบุคคล ตอบกลับได้ในหน้าเดียว (นักเรียนเห็นคำตอบที่หน้า `/profile`)
3. **ข่าวสาร** — เพิ่ม/ลบข่าวประกาศ ที่จะไปแสดงในหน้า `/news` ของนักเรียนทันที
4. **ตั้งค่าแอป** — ตั้งชื่อแอป, โลโก้ (emoji หรือ URL รูปภาพ — v02 ยังไม่รองรับอัปโหลดไฟล์โดยตรง), ข้อความประกาศด่วน

### ตาราง Database ที่เพิ่มเข้ามา
`sessions`, `messages`, `news`, `app_settings` — และตาราง `students` มีคอลัมน์ใหม่ `username`, `password_hash`, `class_room`, `nickname`, `avatar_emoji`, `avatar_color`

### วิธีอัปเดตฐานข้อมูลเดิมให้เป็น v02
เข้า `https://<โดเมนของคุณ>.vercel.app/api/init-db` อีกครั้งครั้งเดียว — สคริปต์ใช้ `CREATE TABLE IF NOT EXISTS` และ schema ใหม่ทั้งหมด ปลอดภัย ไม่ลบข้อมูลเดิม (แต่ถ้าคุณมีนักเรียนที่สมัครไว้ตั้งแต่ v01 จะไม่มี username/password — ต้องให้สมัครใหม่ หรือปรับข้อมูลเองใน SQL editor)

### สิ่งที่ยังไม่ทำ (ไว้ v03)
- ระบบให้คะแนน/แสดงผลแบบทดสอบจริง
- แชทบอทแบบ AI จริง (ตอนนี้เป็น rule-based ธรรมดา)
- อัปโหลดไฟล์โลโก้โดยตรง (ต้องต่อ Vercel Blob Storage เพิ่ม)
- ระบบแจ้งเตือนแบบ real-time (ตอนนี้ต้องรีเฟรชหน้าเอง)

## อัปเดต v03 — มีอะไรใหม่

### หน้าครู = แอปเดียวกับนักเรียน ต่างกันที่สิทธิ์
- เพิ่มแท็บ **"ฟีดนักเรียน"** ในแผงควบคุมครู แสดงโพสต์/คอมเมนต์แบบเดียวกับที่นักเรียนเห็นทุกประการ
- ครูกดไลก์ คอมเมนต์ให้กำลังใจได้ — คอมเมนต์ของครูจะติดป้าย "ครูแนะแนว" ให้นักเรียนเห็นชัดเจน (ครูโพสต์ใหม่ไม่ได้ เพื่อไม่ให้ปนกับพื้นที่ของนักเรียน)
- แยกการตั้งค่าระบบ (โลโก้ ข่าวสาร ประกาศ) ไว้ในแท็บ "ตั้งค่าแอป" ต่างหาก

### ปุ่ม Back และ Logout ครบทุกหน้า
- นักเรียน: ปุ่มย้อนกลับอยู่ทุกหน้า (ยกเว้นหน้าแรก), ปุ่มออกจากระบบอยู่ทั้งใน sidebar (จอกว้าง) และมุมขวาบนของทุกหน้า (มือถือ)
- ครู: เพิ่ม header ใหม่ มีปุ่มย้อนกลับไปหน้านักเรียน และปุ่มออกจากระบบครูโดยเฉพาะ (คนละ session กับนักเรียน)

### ชื่อเล่นแสดงทุกที่ ไม่ใช่ TUNT-xxxx อีกต่อไป
- โพสต์และคอมเมนต์ทุกจุดแสดง **ชื่อเล่น + อวาตาร์** ที่ตั้งไว้ในหน้าโปรไฟล์ (ถ้ายังไม่ตั้งชื่อเล่น จะ fallback ไปที่รหัสบัญชีชั่วคราว)
- ชื่อเล่นเป็นนามแฝง ไม่ใช่ชื่อจริง — เพื่อนนักเรียนยังไม่เห็นตัวตนจริง ครูแนะแนวเท่านั้นที่เห็นชื่อจริงในแดชบอร์ด

### ระบบคอมเมนต์ + แชร์
- ทุกโพสต์คอมเมนต์ได้ กดปุ่ม 💬 เพื่อเปิด/ปิดกล่องคอมเมนต์
- ปุ่มแชร์ใช้ Web Share API ของอุปกรณ์ (มือถือจะเด้งเมนูแชร์จริง) ถ้าอุปกรณ์ไม่รองรับจะคัดลอกข้อความแทน

### แชทบอทพิมพ์คุยได้จริง (ไม่ใช่ AI แต่จับคำสำคัญ)
- เปลี่ยนจากปุ่มตัวเลือกอย่างเดียว เป็นช่องพิมพ์ข้อความอิสระ
- ระบบสแกนคำสำคัญที่พิมพ์มา (เช่น "เครียด", "เพื่อน", "นอนไม่หลับ") แล้วตอบด้วยข้อความที่เตรียมไว้ล่วงหน้า — ดูกฎทั้งหมดได้ที่ `src/lib/botRules.js` แก้ไข/เพิ่มคำได้อิสระ
- ถ้าพิมพ์คำที่บ่งชี้ความเสี่ยงสูง (เช่น "อยากตาย") ระบบจะแจ้งครูแนะแนวทันทีอัตโนมัติ พร้อมให้เบอร์สายด่วน 1323
- ถ้าพิมพ์ "อยากคุยกับครู" ระบบจะส่งข้อความแจ้งครูอัตโนมัติเช่นกัน

### รวมช่องทางติดต่อไว้ที่เดียว
- หน้า `/chat` มี 2 แท็บสลับได้ในหน้าเดียว: **คุยกับ TUNT Bot** และ **คุยกับครูแนะแนว** (ข้อความห้องนี้ครูเห็นชื่อจริงเสมอ)
- ย้ายกล่องข้อความออกจากหน้าโปรไฟล์มารวมไว้ที่นี่ที่เดียว ลดความซ้ำซ้อน

### ปุ่มลอยทรงหยดน้ำ มุมขวาล่าง
- กดเปิดเมนูลัด 2 ทาง: 💬 คุยกับครู/บอท (ไปหน้า `/chat`) และ ☎️ สายด่วนฉุกเฉิน (เปิด modal เบอร์ 1323 และ Samaritans of Thailand)
- แสดงอยู่ทุกหน้าของนักเรียน (ยกเว้นหน้า `/chat` เอง เพื่อไม่ให้ลิงก์วนกลับตัวเอง)

### ตาราง Database ที่เพิ่มเข้ามา
`comments` — เชื่อมกับ `posts` และ `students` เก็บทั้งคอมเมนต์จากนักเรียนและครู

### วิธีอัปเดตฐานข้อมูลเดิมให้เป็น v03
เข้า `https://<โดเมนของคุณ>.vercel.app/api/init-db` อีกครั้ง — สร้างตาราง `comments` เพิ่มเข้ามาแบบปลอดภัย ไม่กระทบข้อมูลเดิม

### สิ่งที่ยังไม่ทำ (ไว้ v04)
- ระบบแจ้งเตือนแบบ real-time (ยังต้องรีเฟรชหน้าเพื่อดูข้อความ/คอมเมนต์ใหม่)
- อัปโหลดไฟล์โลโก้โดยตรง (ต้องต่อ Vercel Blob Storage)
- ระบบลบ/แก้ไขโพสต์และคอมเมนต์ของตัวเอง

## อัปเดต v04 — มีอะไรใหม่

### แนบรูปภาพได้ (ข่าวสาร + โพสต์ระบาย)
- แอดมินแนบรูปตอนเพิ่มข่าวสารได้ (ปุ่ม 📷 ในฟอร์มเพิ่มข่าว)
- นักเรียนแนบรูปตอนโพสต์ในกระดานระบายได้
- **คอมเมนต์ยังคงเป็นข้อความอย่างเดียว** ตามที่ตกลงกันไว้ (ไม่ให้แนบรูปในคอมเมนต์)
- ⚠️ รูปภาพถูกบีบอัดและเก็บเป็น base64 ตรงในฐานข้อมูล (ยังไม่ได้ต่อ Cloud Storage) — เหมาะกับการใช้งานจริงระดับโรงเรียนขนาดกลาง แต่ถ้ามีรูปจำนวนมากในระยะยาว ควรอัปเกรดไปใช้ Vercel Blob Storage ในเวอร์ชันถัดไป

### เรื่องรหัสผ่านนักเรียนที่ลืม — ขอปรับแนวทางเพื่อความปลอดภัย
ที่ขอมาคือ "แอดมินเห็นไอดีและรหัสผ่านของนักเรียน" แต่ระบบเข้ารหัสรหัสผ่านด้วย bcrypt ตั้งแต่ v02 (เข้ารหัสทางเดียว ถอดกลับไม่ได้แม้แต่แอดมิน) ซึ่งเป็นมาตรฐานความปลอดภัยที่ไม่ควรเปลี่ยน โดยเฉพาะเพราะเป็นบัญชีของนักเรียนที่เป็นผู้เยาว์ ถ้าเก็บรหัสผ่านแบบข้อความธรรมดาไว้ แล้ววันหนึ่งฐานข้อมูลรั่วไหล รหัสผ่านของนักเรียนทุกคนจะหลุดไปในครั้งเดียว (และเด็กจำนวนมากมักใช้รหัสผ่านซ้ำกับบัญชีอื่นๆ ความเสี่ยงจึงลามไปไกลกว่าระบบนี้)

**สิ่งที่ทำแทน:** เพิ่มปุ่ม **"🔑 รีเซ็ตรหัสผ่าน"** ในแดชบอร์ดครู กดแล้วระบบจะ
1. สุ่มรหัสผ่านใหม่ให้ (รูปแบบอ่านง่าย เช่น `tunt-4821`)
2. แสดงรหัสใหม่ให้ครูเห็น **ครั้งเดียว** เพื่อไปแจ้งนักเรียนด้วยตนเอง
3. ตัด session เดิมของนักเรียนคนนั้นทิ้งอัตโนมัติ (ต้องล็อกอินใหม่)

ส่วน **ไอดี (username)** แสดงในตารางแดชบอร์ดให้ครูเห็นได้ตามปกติอยู่แล้ว (ไม่ใช่ข้อมูลลับ) ครูสามารถบอกไอดีนักเรียนที่ลืมได้ทันทีจากหน้าแดชบอร์ด

### บอทคุยได้หลากหลายขึ้น
- เพิ่มหมวดคำสำคัญที่จับได้จาก 6 เป็น 12 หมวด (เพิ่มเรื่องอนาคต/สอบเข้า, ความรัก, เกม/โซเชียล, ความเบื่อ/หมดไฟ ฯลฯ)
- แต่ละหมวดมีคำตอบสำรอง 2-3 แบบ สุ่มตอบไม่ซ้ำเดิมทุกครั้ง ดูรายการทั้งหมดและแก้ไขได้ที่ `src/lib/botRules.js`

### ระบบกรองคำหยาบ
- ไฟล์ `src/lib/profanity.js` มีรายการคำต้องห้ามภาษาไทย+อังกฤษ แทนที่ด้วย `***` อัตโนมัติ
- ใช้งานทุกจุดที่นักเรียนพิมพ์ข้อความ: โพสต์ระบาย, คอมเมนต์ (ทั้งนักเรียนและครู), ข้อความถึงครู, และข้อความที่พิมพ์คุยกับ TUNT Bot
- แก้ไข/เพิ่มคำในลิสต์ได้ที่ไฟล์เดียวนี้

### แบบทดสอบพร้อมใช้งานจริงครบ 6 แบบ พร้อมอ้างอิง
ทุกแบบทดสอบมีคำถามจริง ให้คะแนน และแสดงผลจริงแล้ว (ไม่ใช่ "กำลังพัฒนา" อีกต่อไป) ดูคำถามทั้งหมดที่ `src/lib/testBank.js`:

| แบบทดสอบ | ที่มา |
|---|---|
| SDQ (เช็กสุขภาพใจ) | Goodman, R. (1997) + ฉบับแปลไทยกรมสุขภาพจิต (2551) — ใช้ฟรีเพื่อการศึกษา/คลินิกตามเงื่อนไขผู้พัฒนา |
| PHQ-A (สำรวจความเครียดเชิงลึก) | Johnson et al. (2002) + Richardson et al. (2010) |
| บุคลิกภาพ 4 มิติ, ภาษารัก, แนวถนัดอาชีพ, 9 บุคลิกภาพ | คำถามเขียนขึ้นเองทั้งหมดสำหรับ TUNT Space โดยอ้างอิงแนวคิดจิตวิทยาทั่วไปที่เป็นความรู้สาธารณะ **ไม่ใช่การจำลองแบบทดสอบเชิงพาณิชย์ที่มีลิขสิทธิ์ (เช่น MBTI®, 5 Love Languages®) แต่อย่างใด** เพื่อไม่ให้ละเมิดทรัพย์สินทางปัญญาของผู้พัฒนาต้นฉบับ |

**ผล SDQ/PHQ-A เชื่อมกับระบบเฝ้าระวังอัตโนมัติ:** ถ้าผลออกมาระดับสูง ระบบจะส่งข้อความแจ้งเตือนเข้ากล่องข้อความของครูโดยอัตโนมัติทันที (ไม่ต้องรอนักเรียนพิมพ์บอกเอง) และแดชบอร์ดครูจะโชว์ผลล่าสุดของ SDQ/PHQ-A ในตารางด้วย ผลเหล่านี้ถูกนำไปคำนวณระดับความเสี่ยงร่วมกับข้อมูลอื่นๆ

## แก้บั๊ก: โพสต์ข้อความ/รูปไม่ขึ้น (สำคัญ อ่านก่อน!)

**สาเหตุที่แท้จริง:** หลัง deploy v04 ไม่ได้เข้า `/api/init-db` อีกครั้ง ทำให้ตาราง `posts` ในฐานข้อมูล production ไม่มีคอลัมน์ `image_url` ที่โค้ด v04 อ้างอิงถึง ส่งผลให้ **ทั้งการโหลดโพสต์และการสร้างโพสต์ใหม่ล้มเหลวเงียบๆ** (ไม่ว่าจะมีรูปแนบหรือไม่ก็ตาม เพราะคำสั่ง SQL ทั้งก้อนอ้างถึงคอลัมน์ที่ไม่มีจริง)

**วิธีแก้ (ทำทันทีหลัง deploy v05):**
1. เข้า `https://<โดเมนของคุณ>.vercel.app/api/init-db`
2. ต้องเห็น `{"ok":true,"message":"Database ready (v05 schema)"}`
3. รีเฟรชหน้าเว็บ ลองโพสต์ใหม่อีกครั้ง

**ป้องกันปัญหานี้ในอนาคต:** ทุกครั้งที่อัปเดตเวอร์ชันใหม่ ให้เข้า `/api/init-db` เป็นขั้นตอนสุดท้ายเสมอ (ทำได้บ่อยแค่ไหนก็ได้ ไม่มีผลเสีย เพราะใช้ `IF NOT EXISTS` ทุกคำสั่ง)

นอกจากนี้ยังปรับปรุงให้ระบบแจ้ง error ชัดเจนขึ้นเมื่อโหลด/โพสต์ล้มเหลว (ก่อนหน้านี้จะเงียบและดูเหมือนไม่มีอะไรเกิดขึ้น ตอนนี้จะมีข้อความแจ้งเตือนสีแดงบอกสาเหตุ พร้อมปุ่ม "ลองใหม่")

## อัปเดต v05 — มีอะไรใหม่

### Export ผลแบบทดสอบ
- ปุ่ม "📊 Export ผลแบบทดสอบ (CSV)" ที่แดชบอร์ดครู ดาวน์โหลดผลแบบทดสอบทุกคน ทุกครั้งที่ทำ เปิดได้ตรงใน Excel/Google Sheets
- **หมายเหตุ:** ทำเป็น CSV แทน .xlsx จริง เพราะ CSV เปิดใน Excel ได้สมบูรณ์อยู่แล้วโดยไม่ต้องติดตั้งไลบรารีเพิ่ม (ลดความเสี่ยงเรื่อง bundle ใหญ่/ช้าลงบน serverless) ถ้าต้องการไฟล์ .xlsx จริงในอนาคตแจ้งได้ จะเพิ่มให้

### ครูลบโพสต์ได้ / นักเรียนลบโพสต์ตัวเองได้
- ปุ่มถังขยะ 🗑️ มุมขวาบนของแต่ละโพสต์ในกระดานระบาย
- ครูเห็นปุ่มนี้ในทุกโพสต์ นักเรียนเห็นเฉพาะโพสต์ของตัวเอง

### โลโก้แอปอัปโหลดเป็นรูปภาพได้จริง
- แท็บตั้งค่าแอปของครู มีปุ่ม "📷 อัปโหลดรูปโลโก้" อัปโหลดแล้วจะไปแสดงผลทันทีทุกหน้า (sidebar, หน้า login/register, header)
- ยังใส่เป็น emoji/ข้อความสั้นแทนได้เหมือนเดิมถ้าไม่อยากใช้รูป

### เรื่อง "ตั้งค่าได้ทุกอย่าง"
ทำได้ตามความเป็นจริงในเวลาที่มี ตอนนี้ตั้งค่าได้: ชื่อแอป, โลโก้, ประกาศด่วน (จากเดิม) — สิ่งที่ตั้งใจ **ไม่ทำ** คือให้แก้เบอร์สายด่วนฉุกเฉิน (1323) เอง เพราะเป็นข้อมูลความปลอดภัยที่สำคัญ ไม่อยากให้เผลอตั้งค่าผิดพลาดได้ ถ้าต้องการเพิ่มสายด่วนอื่นในอนาคตแจ้งได้ จะทำเป็นฟีเจอร์แยกที่มีการยืนยันความถูกต้องก่อนบันทึก

### กิจกรรมใหม่: บันทึกขอบคุณประจำวัน (Gratitude Journal)
- หน้า `/gratitude` ให้นักเรียนเขียนสิ่งเล็กๆ ที่รู้สึกขอบคุณในแต่ละวัน พร้อมระบบนับวันต่อเนื่อง (streak) แบบเดียวกับการเช็กอินอารมณ์
- อิงหลักจิตวิทยาเชิงบวก (Positive Psychology) ที่มีงานวิจัยรองรับว่าการเขียนบันทึกขอบคุณสม่ำเสมอช่วยเพิ่มความรู้สึกเป็นสุขได้จริง
- มีลิงก์เข้าถึงจากการ์ดใหญ่ในหน้าแรก

### ปรับดีไซน์: neo-brutalism ผสม neumorphism
- วงกลมเช็กอินอารมณ์หน้าแรก และกล่องเขียนบันทึกขอบคุณ ปรับให้มีเงานุ่มด้านในผสมกับเงาแข็งด้านนอกแบบเดิม ให้ความรู้สึกนุ่มขึ้นแต่ยังคงความสดใสชัดเจนแบบ neo-brutalism
- **หมายเหตุ:** ปรับเฉพาะจุดเด่นๆ ก่อน (ยังไม่ได้ไล่ปรับทุก input/ปุ่มทั้งแอป) เพื่อคุมเวลาทำงาน ถ้าชอบทิศทางนี้แจ้งได้ จะขยายผลไปทั่วทั้งแอปในเวอร์ชันถัดไป

### ตาราง Database ที่เพิ่ม

- Export เป็น .xlsx/PDF จริง
- ย้ายรูปภาพไป Cloud Storage

## อัปเดต v06 — รีดีไซน์ UX/UI ทั้งระบบ (Netflix/Disney+ inspired)

### แนวคิดการออกแบบใหม่
- **พื้นหลังเข้มหรูหรา** แทนพื้นหลังเหลืองสดใสจัดจ้านแบบเดิม — ใช้ gradient กรมท่า-ม่วงเข้ม (`#0C0E22` → `#171A3A`) พร้อมแสง glow นุ่มๆ มุมจอ ให้ความรู้สึกแบบหน้าแรก Netflix/Disney+
- **การ์ดเนื้อหายังคงเป็นสีขาวขอบดำหนา + เงาแข็ง** (neo-brutalism เดิม) แต่เพิ่มเงานุ่มด้านใน (neumorphism) ในจุดเด่นอย่างวงกลมเช็กอินอารมณ์และกล่องเขียนบันทึก ผสมสไตล์ทันสมัยเข้ากับความสดใสแบบเดิม
- สีสัน 6 โทน (เหลือง/ส้ม/มินต์/ม่วง/ฟ้า/ชมพู) ยังคงอยู่ครบ แต่ใช้เป็น **accent** (ไอคอนแบดจ์, แท็ก, การ์ดแนวนอน) แทนการทาสีเต็มพื้นหลังใหญ่ๆ ทำให้ดูสดใสแต่ไม่ฉูดฉาดเกินไปตามที่ขอ

### โครงสร้างหน้าแบบ Netflix/Disney+
- **หน้าแรก**: ปรับเป็น Hero Panel ใหญ่ด้านบน (ทักทาย + เช็กอินอารมณ์) ตามด้วย**แถวเลื่อนแนวนอน** 3 แถว: "สำรวจวันนี้", "แบบทดสอบแนะนำ", "ข่าวสารล่าสุด" (ดึงรูปข่าวจริงมาโชว์เป็นการ์ดโปสเตอร์)
- **หน้าแบบทดสอบ**: จัดกลุ่มเป็น genre-row แบบ Netflix ตามหมวด "ดูแลใจ / แนะแนวอนาคต / สนุกกับตัวเอง" แต่ละแถวเลื่อนแนวนอนได้อิสระ การ์ดมีรูปพื้นหลังสีตามหมวดคล้ายปกซีรีส์
- Sidebar/Header/Bottom nav ปรับเป็นธีมเข้มเข้าชุดเดียวกันทั้งหมด ปุ่มที่ active เน้นด้วยสีเหลืองสดตัดกับพื้นเข้ม

### ระบบสี — เทคนิคที่ใช้แก้ปัญหาคอนทราสต์
เนื่องจากเปลี่ยนพื้นหลังหลักเป็นสีเข้ม แต่การ์ดเนื้อหายังเป็นสีขาว จึงเพิ่มกฎ CSS ให้การ์ดสีขาวทุกใบ (`.card`, `.card-sm`) รีเซ็ตสีตัวอักษรกลับเป็นสีเข้มให้อัตโนมัติ ป้องกันปัญหาตัวอักษรจางอ่านไม่ออกบนพื้นขาว ส่วนข้อความที่อยู่บนพื้นเข้มโดยตรง (ไม่ได้อยู่ในการ์ด) ปรับเป็นสีเทาอ่อน/ขาวให้อ่านง่ายครบทุกจุดที่ตรวจสอบแล้ว

- Mobile: Bottom nav เข้าธีมเดียวกัน แถวเลื่อนแนวนอนใช้นิ้วปัดได้ลื่นไหลเหมือนแอป streaming จริง

### ขอบเขตที่ปรับ (เพื่อความปลอดภัยและความเร็วในการส่งมอบ)
รีดีไซน์ครอบคลุม: หน้า login/register, home, tests, และโครงสร้าง AppShell ที่ทุกหน้า (feed, chat, profile, news, gratitude) ใช้ร่วมกัน — ทำให้ทุกหน้าได้ธีมใหม่ไปโดยอัตโนมัติแล้ว ส่วนหน้าครูปรับพื้นหลังให้เข้าชุดเช่นกัน (การ์ดขาว/ม่วงด้านในยังคงเดิม)

**ยังไม่ได้ทำ:** การปรับโครงสร้างหน้า feed/chat/profile ให้มีเลย์เอาต์แบบ "แถวโปสเตอร์" เชิงลึกแบบหน้า home/tests (ตอนนี้ยังเป็นลิสต์แนวตั้งแบบเดิม เพียงแค่เปลี่ยนโทนสีพื้นหลัง) — ถ้าต้องการให้ปรับหน้าเหล่านี้ให้มีเลย์เอาต์แบบ browsing มากขึ้นด้วย แจ้งได้ในเวอร์ชันถัดไป

### ไม่มีการเปลี่ยนแปลงฐานข้อมูล
v06 เป็นการปรับ UI/UX ล้วนๆ ไม่มีตารางใหม่ **ไม่จำเป็นต้องเข้า `/api/init-db` ซ้ำ** (แต่เข้าซ้ำได้เสมอโดยไม่มีผลเสีย)

## อัปเดต v07 — ปรับธีมจากเข้มเป็นสว่างสดใส (คงเลย์เอาต์ Netflix/Disney+ เดิม)

v06 ทำธีมเข้มหรูหราแบบ Netflix ไปก่อน แต่รอบนี้ปรับกลับเป็น**โทนสว่าง อ่านง่าย** ตามที่ขอ โดย**คงโครงสร้างเลย์เอาต์แบบ Netflix/Disney+ ไว้ทั้งหมด** (Hero Panel, แถวเลื่อนแนวนอน, genre-row จัดกลุ่มแบบทดสอบ) — เปลี่ยนแค่ระบบสี ไม่ได้ทุบโครงสร้างทิ้ง

### สิ่งที่เปลี่ยน
- พื้นหลังหลัก: จาก gradient กรมท่าเข้ม → **ครีมอุ่นสว่าง** (`#FFF9F0`) พร้อมแสง glow สีม่วง/ส้มพาสเทลจางๆ มุมจอ ให้ความรู้สึกพรีเมียมแต่สว่างสบายตา
- Sidebar / Header / Bottom nav: จากพื้นเข้ม → **พื้นขาว/ครีมสว่าง** พร้อมเส้นขอบดำหนา 3px แบบ neo-brutalism ต่อเนื่องกับดีไซน์การ์ดเดิม (จากเดิมที่ v06 ใช้เส้นบางแบบ Netflix ล้วนๆ)
- ปุ่มเมนูที่ active: ตัวหนังสือสีเข้มบนพื้นเหลืองสด (จากเดิมตัวหนังสือสีอ่อนซึ่งใช้ได้เฉพาะบนพื้นเข้ม)
- Hero Panel หน้าแรก: จากพื้นเข้ม → **gradient ขาว-ส้มพีชอ่อน** พร้อมเงานุ่มด้านในแบบ neumorphism เหมือนเดิม
- แผงแบรนด์หน้า login/register: จากมืด → **gradient ส้มพีช-เหลืองสด** ตัวหนังสือขาวขอบเงาดำหนา (สไตล์โปสเตอร์การ์ตูน)
- **แก้จุดคอนทราสต์ทุกจุดที่เคยปรับไว้สำหรับพื้นเข้มใน v06** ให้กลับมาเหมาะกับพื้นสว่างแทน (ลิงก์ท้ายฟอร์ม, ป้ายกำกับต่างๆ) — ตรวจแล้วด้วยภาพหน้าจอจริงทุกหน้า

### สิ่งที่ไม่เปลี่ยน (ตามที่ตั้งใจไว้)
- โครงสร้าง Hero Panel + แถวเลื่อนแนวนอนของหน้าแรกและหน้าแบบทดสอบ ยังเหมือน v06 ทุกประการ
- สีสัน 6 โทน (เหลือง/ส้ม/มินต์/ม่วง/ฟ้า/ชมพู) ที่ใช้เป็น accent ในการ์ดต่างๆ ยังเหมือนเดิม
- ฟังก์ชันการทำงานทั้งหมดไม่มีการเปลี่ยนแปลง

### ไม่มีการเปลี่ยนแปลงฐานข้อมูล
v07 เป็นการปรับสีธีมล้วนๆ **ไม่จำเป็นต้องเข้า `/api/init-db` ซ้ำ**

## อัปเดต v08 — รื้อ UX/UI ใหม่ทั้งหมด (มาสคอตหัวใจ + สไตล์แอปเพื่อนคู่ใจ)

หลังจากลองมาหลายทิศทาง (neo-brutalism v5, ธีมเข้ม v6, ธีมสว่าง v7) รอบนี้เป็นการรื้อใหม่ทั้งระบบตามภาพอ้างอิงที่ยืนยันแล้วว่าชอบ — สไตล์ "แอปเพื่อนคู่ใจ" น่ารัก โค้งมน มีมาสคอต

### สิ่งที่เปลี่ยนหลัก
- **มาสคอตหัวใจยิ้ม** (SVG วาดเอง ไม่ต้องพึ่งไฟล์รูป) แทนโลโก้กล่อง "ใจ" เดิมทุกจุด — sidebar, หน้า login, การ์ดเช็กอินอารมณ์
- **โค้งมนทั้งระบบ** เปลี่ยนจากขอบเหลี่ยมเส้นหนา 3px แบบ neo-brutalism เป็นขอบโค้ง (16-26px) เส้นบาง + เงานุ่มลอยตัว
- **ฟอนต์หัวเรื่องใหม่**: Mitr (ฟอนต์ไทยโค้งมนเป็นมิตร) แทน Prompt ตัวหนาเหลี่ยม
- **โทนสีใหม่**: ม่วง #6E4FE0 (sidebar/ปุ่มหลัก), เหลืองทอง #FFC736, มินต์ #3ED6B8, ชมพูโคอรัล #FF6F91 — พาสเทลสดใสแต่นุ่มนวล
- **Sidebar เป็นพื้นม่วงเข้ม** พร้อมการ์ดโปรไฟล์แสดงชื่อเล่น+อวาตาร์+ชั้นเรียนอยู่ใต้โลโก้ (จากเดิมที่ไม่มี)
- **ปุ่มทั้งหมดเป็นทรงแคปซูลโค้งมน** (pill-shape) พื้นม่วง ตัวหนังสือขาว แทนปุ่มเหลี่ยมเงาแข็งเดิม
- หน้าแรกจัดเป็น การ์ดเช็กอินอารมณ์ + การ์ดสายด่วนคู่กัน, แถวภารกิจ/รางวัลพร้อม progress bar โค้งมน, แถวสำรวจ, แถวแบบทดสอบแนะนำ, แถวข่าวสาร — เค้าโครงแบบ Netflix/Disney+ เดิมยังคงอยู่ แค่เปลี่ยนสไตล์การ์ดให้น่ารักขึ้น

### สถาปัตยกรรมที่ช่วยให้ทำได้เร็ว
เนื่องจากทุกหน้าอ้างอิง CSS class กลาง (`.card`, `.card-sm`, `.btn-brut`, `.font-display`) และตัวแปรสี (`--purple`, `--coral` ฯลฯ) ผ่าน `globals.css` ที่เดียว การรีสกินรอบนี้จึงทำได้โดยแก้ไฟล์หลักไม่กี่ไฟล์ (globals.css, AppShell, AuthLayout, หน้า login/register/home) แล้วหน้าที่เหลือ (feed, chat, profile, news, gratitude, teacher) **ได้ธีมใหม่ไปโดยอัตโนมัติ** เพราะใช้ class เดียวกันอยู่แล้ว — ตรวจสอบและแก้จุดคอนทราสต์ที่หลงเหลือจากธีมเก่าครบทุกจุดแล้ว (ปุ่มพื้นขาวไม่ตั้งสีตัวอักษรไว้ 6 จุดที่พบและแก้ไข)

### ทดสอบแล้ว
สมัคร/ล็อกอิน/ตั้งชื่อเล่น/โพสต์/genre-row แบบทดสอบ ผ่าน curl + screenshot จริงทั้ง desktop (sidebar) และ mobile (bottom nav) เทียบกับ mockup ที่คอนเฟิร์มแล้วตรงกัน

### ไม่มีการเปลี่ยนแปลงฐานข้อมูล
v08 เป็นการปรับดีไซน์ล้วนๆ **ไม่จำเป็นต้องเข้า `/api/init-db` ซ้ำ**
